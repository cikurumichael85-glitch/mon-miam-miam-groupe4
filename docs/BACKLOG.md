# Backlog GitHub relié à Jira

51 tâches techniques, reliées aux 51 tâches de travail préparées dans Jira. Les cinq lots Jira ne sont pas dupliqués en tâches supplémentaires. Import de préparation du 22/10/2026 ; pas de synchronisation automatique des statuts. Les priorités et responsables restent des propositions de réalisation.

Jira reste la référence du suivi fonctionnel ; GitHub accueille les discussions techniques, branches, commits et pull requests. Ne pas conclure qu’une fonctionnalité est terminée à partir d’une case ou d’une issue fermée sans relire ses critères et preuves.
