## Flux

Branche nominative → PR vers integration → tests et relecture → PR integration vers main.
Pas de push direct sur main ou integration. Fusion normale pour conserver les commits individuels. La présence de branches ne constitue pas une protection serveur active.

Lire [les conventions](CONTRIBUTING.md), [l'ordre des 15 lots](docs/nouveau-depot/ORDRE_COMMITS_ET_INTEGRATION.md) et [le manifeste complet](docs/nouveau-depot/TOUS_LES_FICHIERS_ET_COMMITS.csv).
Les lots de code sont remis dans les dossiers locaux individuels ; ils ne sont pas committés automatiquement.

## Origine et limites

Les sources proviennent de [l’ancien dépôt au commit c65a206](https://github.com/cikurumichael85-glitch/mon-miam-miam/tree/c65a2066db0311a46824e8c8de56b26513d6b1a0). Voir la [provenance](docs/nouveau-depot/PROVENANCE.json). L’historique précédent est conservé dans l’ancien dépôt. Les nouveaux commits décrivent des imports et leur prise en main réelle.

Le site actuellement hébergé continue à utiliser l'ancien dépôt. Ce dépôt n'active aucun paiement et ne copie ni comptes, ni commandes, ni secrets. La réception d'une autorisation Mobile Money et l'encaissement réel restent à vérifier avec le prestataire.

Jira suit les tâches ; Figma porte les maquettes ; GitHub conserve les sources, PR et preuves. Les mises à jour Jira sont manuelles. Les documents historiques ne prouvent ni une recette actuelle ni une contribution individuelle passée.
